PERSONAL PORTFOLIO TKJ

Cara menjalankan:
1. Ekstrak file ZIP.
2. Buka folder portfolio_tkj.
3. Klik dua kali index.html atau buka dengan browser.

Yang perlu diedit:
- Ganti [Nama Kamu] di index.html dengan nama lengkap.
- Ganti emailkamu@example.com, tautan Instagram, GitHub, dan nomor WhatsApp pada bagian Contact.
- Foto profil sudah disimpan sebagai assets/profile.jpg.
- Untuk tombol Download CV, tambahkan file CV milikmu dan ubah tombol sesuai file CV tersebut jika diperlukan.

Website dibuat menggunakan HTML, CSS, dan JavaScript murni.
